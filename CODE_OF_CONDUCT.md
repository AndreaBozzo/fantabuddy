# Codice di condotta

Fantabuddy vuole essere uno spazio rilassato e utile. Nelle issue, Discussion, review
e pull request:

- critica idee e codice, non le persone;
- dai contesto e tratta con rispetto chi ha esperienza diversa dalla tua;
- evita molestie, discriminazioni, contenuti sessuali o pubblicazione di dati altrui;
- accetta le decisioni di moderazione e aiuta a riportare la conversazione sul tema.

Comportamenti inaccettabili possono essere rimossi e, se necessario, portare al blocco
dell'account dal progetto. Per segnalazioni riservate usa i contatti privati disponibili
sul profilo GitHub del maintainer.
